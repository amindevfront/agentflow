AgentFlow

Cada tela é um fluxo em andamento — nunca uma coleção de cartões parados.

O AgentFlow existe para tirar trabalho repetitivo das mãos de equipes. Por isso a interface inteira gira em torno de um único elemento — o trilho de fluxo, a linha que liga cada etapa à próxima — em vez de painéis genéricos de métricas. Se a tela não mostra um processo se movendo, ela está errada para este produto.

Fluxo contínuo — telas mostram sequência, não fragmentos soltos
Um sinal por vez — azul é ação; cor de estado nunca é decoração
Densidade com hierarquia — nada de espaço vazio decorativo
Estado sempre visível — o usuário nunca pergunta "isso rodou?"

Uma paleta funcional, não decorativa

Azul é o único acento de marca — usado em ações, foco e presença de marca. Âmbar, verde e vermelho existem exclusivamente para indicar estado de execução: nunca aparecem em botões, links, títulos ou qualquer elemento que não seja um indicador de status.
